# حوّلها — معاينة التصميم

معاينة HTML/CSS/JavaScript عربية RTL ببيانات توضيحية مصنوعة، دون تسجيلات أو تفريغات مستخدمين.

لا تنشئ حسابات ولا ترفع ملفات ولا تتصل بمزود ذكاء اصطناعي أو دفع. التنزيل غير متاح في المعاينة. التطبيق الكامل Laravel في المستودع الخاص.

لتفعيل الرابط: Settings → Pages → Deploy from a branch → main → / (root) → Save.
الرابط المتوقع بعد نجاح النشر: https://drhatemgamalalshafie.github.io/awwelha-preview/

يُعاد توليد هذه المعاينة من المكونات نفسها بواسطة scripts/build-preview.py في المستودع الخاص، ومن بيئة الاختبار المعزولة فقط.
